Privacy policy: YT Publisher

Last updated: 17 November 2026

YT Publisher is a private tool used only by its owner to manage the owner's own YouTube channels. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data it accesses

  • The signed-in channel's ID and title, used to make sure uploads go only to the intended channel.
  • Videos, thumbnails and captions that the owner uploads or edits on their own channel.
  • Read-only statistics and analytics for the owner's own videos (views, watch time, retention, impressions, click-through rate).

How data is stored and used

  • The sign-in token is stored only on the owner's own computer, in the macOS Keychain.
  • Statistics are saved as local files on the owner's computer, used only to decide how to improve the owner's own videos.
  • No data is sold, shared with third parties, or used for advertising.
  • No data about other people's channels or viewers' personal information is collected.

Retention and deletion

Local statistics files are kept until the owner deletes them. Access can be revoked at any time at Google Account → Security → Third-party access; this invalidates the stored token.
